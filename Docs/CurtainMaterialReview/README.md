# Prévia dos materiais de cortina

Renderizações do Unity com os materiais de `Materials/Active`, aplicados à malha do aplicativo. Cada vista geral representa **300 × 200 cm**. O fundo azul com barras ajuda a observar os vazados.

A iluminação é de estúdio e serve para revisar a trama. Cores, escala física e aparência em AR dependem da iluminação e de comparação com uma amostra real.
